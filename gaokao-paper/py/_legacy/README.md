# 遗留代码

`splitter.py.bak` 是早期的拆题实现，已被 `extract3.py` 完全取代。

**为什么保留而非直接删除**：
它的行聚合与题号识别逻辑记录了最初的探索路径，
对照阅读可以理解 `extract3.py` 中某些「看起来奇怪」的判断条件
（如允许 `( ) 16.` 这类残留前缀）是怎么来的。

**为什么不放回 py/ 根目录**：
它与 `extract3.py` 有同名函数（`extract`），
同时存在会让维护者分不清该改哪个。

**pdfsplit.py 不是遗留代码** —— 它的 `page_lines()`
被 `extract3.py` 引用，必须保留。
