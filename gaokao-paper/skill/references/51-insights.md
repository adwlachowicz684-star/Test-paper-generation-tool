# 题型结论速查：录入中攒下的通法与易错点

> 这一篇不是操作手册，是**做题与审题的收获**。
> 每录一批题，把「这题为什么这么解」「哪儿最容易错」沉淀到这里。
> 按一级知识点编排，每条末尾都标了来源题号 `M-T-xxx-Vn`，需要完整推导就去翻那道题的 `review`。

## 怎么用

```bash
python3 tools/insights.py                     # 全量，按知识点分组
python3 tools/insights.py --kp 解析几何         # 只看某知识点
python3 tools/insights.py --kp 计数原理 --md    # 输出可粘贴的 Markdown 片段
python3 tools/insights.py --topic M-T-374       # 只看某题型
python3 tools/insights.py --check               # 与本文对账，列出未收录的结论
```

**录入新题时**，如果 review 里写了 `⭐` 开头的心得，顺手把它加进本文对应章节。
题号必须标 —— `--check` 靠题号对账，漏标会被误报为「未收录」。

积累一年，这份文档会是这套题库最有价值的部分：它记的不是题目，是**怎么想**。

## 不等式

### 绝对值（M-T-026）

**绝对值三大公式**

$$\lvert x-a\rvert\le m\iff a-m\le x\le a+m$$
$$\lvert x-a\rvert+\lvert x-b\rvert\ge\lvert a-b\rvert$$
$$f(x)>c\ \text{恒成立}\iff f_{\min}>c$$

| 结论 | 来源 |
|---|---|
| 「$f(x)\ge c$ 恒成立」⟹ 先求 $f_{\min}$，再令 $f_{\min}\ge c$ | M-T-026-E1 |
| 解含 $\lvert a\rvert$ 的不等式**必须分 $a\ge0$、$a<0$**，即便某支无解也要验证 | M-T-026-V1 |
| 「方程有解」$\iff$ 左边最小值 $\le$ 右边；**上下夹逼**（三角不等式给下界、基本不等式给上界）是求参数取值的经典手法 | M-T-026-V2 |
| $f(x)>c$ 是**严格大于**，端点处 $f_{\min}=c$ 不满足，必须取**开区间**（若题干是 $\ge$ 才可闭） | M-T-026-V3 |

## 函数与导数

### 中心对称与奇函数（M-T-048）

**三步套路**：构造奇函数（减常数）→ 用单调性脱 $g$ → 分离参数求最值。（M-T-048-V3）

> 「$f(a)+f(b)<4$」里的 $4$ 就是提示：$f$ 的中心是 $(0,2)$，$4=2+2$，所以**减 $2$ 造奇函数**。

凡 $M+N$ 型（而非 $M-N$）多半是这个结构：「分离常数 + 奇函数最值互为相反数」。（M-T-048-V2）

### 构造辅助函数（M-T-122 / 123 / 124）

| 结论 | 来源 |
|---|---|
| $g(\frac\pi2)=0$ 只说明 $\cos\frac\pi2\cdot f(\frac\pi2)=0$，这是**恒等式**，对 $f(\frac\pi2)$ 无约束 —— 单调性在此失效 | M-T-123-E1 |
| 用 $\mathrm e^{x-1}$ 而非 $\mathrm e^{x}$ 是为了让 $\mathrm e^{0}=1$，使 $g(1)=f(1)-1=2$ 计算最简；用 $\mathrm e^{x}$ 结论相同但数字变丑 | M-T-124-V2 |
| 整数解要**挨个验**：$m\in(-\mathrm e,0]$ 时 $f(-1)=-\mathrm e<m$ ✓，而 $f(0)=1>m$（$0$ **不在**解集中），别想当然 | M-T-122-V2 |
| 构造 $g(x)=xf(x)-x$ 后 $g'=f+xf'-1>0$，用单调性把不等式两边脱掉 | M-T-122-V1 |

### 导数中的「距离」（M-T-136）

| 结论 | 来源 |
|---|---|
| 两条曲线**分居 $y=x$ 两侧**时，最短距离 = 各自到 $y=x$ 最短距离之和（连线垂直于 $y=x$ 时取到） | M-T-136-E1 |
| 见到「$X^{2}+Y^{2}$」形式先想**两点距离**；两点分属互为反函数的两条曲线时，最短距离 $=2\times$ 到 $y=x$ 的距离 | M-T-136-V1 |
| $\lvert AB\rvert$ 的导数 $h'(a)=\mathrm e^{a}-\frac1a$ **恰好就是**切线平行条件 $g(a)$ —— 不是巧合：距离取极值时两曲线切线必平行 | M-T-136-V2 |
| 圆心取在 $(\mathrm e+\frac1{\mathrm e},0)$ 是「$x+\frac1x$」结构，为了让最优点横坐标恰好是 $\mathrm e$ | M-T-136-V3 |

### 单调性与求参（M-T-108 / 110 / 404）

最容易混的一对：

| 题型 | 条件 | 看什么 |
|---|---|---|
| 在 $I$ 上**是**增函数 | $f'\ge0$ **恒成立** | 最**小**值 |
| 在 $I$ 上**存在**增区间 | $f'>0$ **有解** | 最**大**值 |

「恒成立」和「有解」搞反，答案直接反过来。

另外 $f'(x)\ge0$ 用的是 $\ge$ 不是 $>$ —— $f'=0$ 只在孤立点成立时函数仍严格递增（如 $y=x^{3}$），
错用 $\Delta<0$ 会漏算 $(a-1)^{2}=b^{2}$ 的情形。（M-T-404-V1）

## 三角函数

### 解三角形（M-T-190 / 195 / 196 / 205）

| 结论 | 来源 |
|---|---|
| **射影定理提速**：$a\cos C+c\cos A=b$ 一步到位，比正弦定理化 $\sin(A+C)$ 再转 $\sin B$ 快得多，两者等价 | M-T-196-E1 |
| 见 $(\sin B+\sin C)^{2}-\sin^{2}A$ 型：**先换成边**再配余弦定理，最后用 $b^{2}+c^{2}\ge2bc$ 求最值 | M-T-190-E1 |
| 「锐角」条件**不能漏**：只给 $B+C=\frac{2\pi}3$ 会得到更大范围，答案就错了 | M-T-190-V3 |
| 「扩展线」型：用一条线段串起两个三角形，**各用一次正弦定理再联立** | M-T-205-E1 |
| 不必真求 $x,y$，配成关于 $m$ 的二次式找最小值点，回代算面积即可 | M-T-205-V2 |
| 取 $\angle BAD=B$ 使 $\triangle ABD$ 等腰（$AD=BD$），同时 $\angle CAD=A-B$ 正好接上已知 $\cos(A-B)=\frac18$ —— **一个构造解决两件事** | M-T-205-V3 |
| $T\cos B$ 里的 $T$ 是 $t$ 的**最大值**，不是变量 —— 必须先定 $T$ 再算 $\cos B$ | M-T-195-V2 |

### 四心（M-T-210）

**判断轨迹过哪个「心」，就与对边点乘**：

$$\vec{AP}=t\left(\frac{\vec{AB}}{\lvert AB\rvert\cos B}+\frac{\vec{AC}}{\lvert AC\rvert\cos C}\right)\Rightarrow \text{垂心}$$

代入 $C=\frac{5\pi}6-B$ 后 $\sqrt3\cos B$ 项**恰好抵消** —— 这是命题人设计好的，
否则 $m$ 会依赖 $B$，就不是定值了。（M-T-210-E1、M-T-210-V1）

## 平面向量

### 解析几何中的向量（M-T-242）

| 结论 | 来源 |
|---|---|
| 看出 $\vec{MA}\cdot\vec{BA}=\lvert MA\rvert^{2}$，利用 $\vec{MA}\cdot\vec{MB}=0$ 直接消掉一项，避免引入两个动点 | M-T-242-E1 |
| 圆上点的向量线性组合仍在圆上 ⟹ 用「弦中点分解」$\vec{OA}\cdot\vec{OB}=\lvert OH\rvert^{2}-\lvert AH\rvert^{2}$ 最省事 | M-T-242-V1 |
| **值得背**：双曲线 $x^{2}-y^{2}=a^{2}$ 上任意点到渐近线的距离，与该垂足到原点距离之积为定值 $\frac{a^{2}}2$ | M-T-242-V3 |
| ⚠ 题干写 `ON ⋅ MN` 若按向量点积因 $ON\perp MN$ 恒为 $0$，而答案非零 —— 则必是**长度乘积** $\lvert ON\rvert\cdot\lvert MN\rvert$ | M-T-242-V3 |

## 解析几何

### 双曲线：内心与重心（M-T-374）★ 最有价值的公式

**通用公式**：过 $F_{2}$ 作渐近线的平行线交双曲线于 $P$，则 $\triangle PF_{1}F_{2}$ 的内切圆半径

$$r=\frac{2S}{\text{周长}}=\frac{b(e-1)}{e+1}\qquad\Big(\text{周长}=a(e+1)^{2}\Big)$$

| 内切圆半径 | $\dfrac{e-1}{e+1}$ | 离心率 |
|---|---|---|
| $\dfrac b3$ | $\dfrac13$ | $e=2$ |
| $\dfrac b4$ | $\dfrac14$ | $e=\dfrac53$ |

一般地 $r=\dfrac bk$ 时 $e=\dfrac{k+1}{k-1}$。内切圆越扁，离心率越接近 $1$。（M-T-374-V2、M-T-374-V3）

**核心结论**：双曲线上一点 $P$ 与两焦点构成的 $\triangle PF_{1}F_{2}$，
**其内切圆与 $x$ 轴的切点必是顶点**。
推导只用切线长定理 + 双曲线定义：设切点 $C(t,0)$，则
$PF_{1}-PF_{2}=F_{1}C-F_{2}C=2t=2a$ → $t=a$。（M-T-374-V1）

### 圆锥曲线其他（M-T-331 / 343 / 363）

| 结论 | 来源 |
|---|---|
| 「判断横放竖放」：同一个方程因参数符号不同，可能是椭圆也可能是双曲线，**必须分情况** | M-T-363-E1 |
| 复数轨迹命门：一看「距离和为常数」就选椭圆是错的 —— 必须**先比较常数与两定点距离**，$\lvert ZA\rvert+\lvert ZB\rvert=\lvert AB\rvert$ 时轨迹是**线段** | M-T-343-V2 |
| 焦点弦定比分点：$\dfrac{c^{2}}{a^{2}}=\dfrac{\lambda-1}{\lambda+3}$ 要开方，原书有处写成 $\frac ca$ 漏了平方，按 $e=\sqrt{\frac{\lambda-1}{\lambda+3}}$ 才对得上答案 | M-T-331-E1 |

## 计数原理

### 球放盒子（M-T-381 / 382）—— 先判断球是否相同

| 情形 | 方法 | 公式 |
|---|---|---|
| 球**相同**，盒不同，允许空 | 隔板法 | $\mathrm C_{n+m-1}^{m-1}$ |
| 球**相同**，盒不同，每盒 $\ge1$ | 隔板法 | $\mathrm C_{n-1}^{m-1}$ |
| 球**不同**，盒不同，每盒 $\ge1$ | 满射 | $m!\,S(n,m)$ |

| 结论 | 来源 |
|---|---|
| **数字差极大**：$7$ 个相同球入 $4$ 盒每盒不空是 $20$；若球**不同**则是 $4!\,S(7,4)=8400$ | M-T-382-V1 |
| 球**不同**、盒**不同**用组合数分步；若改成「$5$ 个**相同**球入 $3$ 盒每盒 $1\sim2$ 个」，答案只有 $3$ 种 | M-T-381-V1 |
| 「至少」型两步走：① 先按最低要求预放化为 $x_{i}\ge0$；② 套 $\mathrm C_{n+m-1}^{m-1}$ | M-T-382-E1 |
| 换元时**减的数要比下限少 $1$** 凑出「$\ge1$」；若直接减下限凑出「$\ge0$」就改用 $\mathrm C_{n+m-1}^{m-1}$ —— 殊途同归 | M-T-382-V2 |
| 通用结论：$n$ 个不同球入 $m$ 个不同盒、每盒不空 ⟺ $m!\,S(n,m)$。$S(5,3)=25$、$S(4,3)=6$ 记住能省一次分类 | M-T-381-V2 |
| 限制简单（如「某两元素不能同组」）时**补集法更快**：总数 $36$ 减去违规 $6$ | M-T-381-V3 |

### 插空与定序（M-T-380）

**模型总结**：「保持原有顺序不变，插入 $k$ 个新元素」
$\iff$ 从 $n+k$ 个位置中选 $k$ 个给新元素排列，即 $\mathrm A_{n+k}^{k}$。（M-T-380-V3）

书架插书、节目插空**是同一个模型**，答案都是 $504$（$n=6,k=3$ → $\mathrm A_{9}^{3}$）。（M-T-380-V2）

### 其他（M-T-383 / 387 / 388）

| 结论 | 来源 |
|---|---|
| **反射原理**：把「相交」转化为「交换终点」—— 甲 $A\to B$ 配乙 $C\to D$（相交）⟷ 甲 $A\to D$ 配乙 $C\to B$（必相交） | M-T-383-V3 |
| 中间平台把楼梯「切断」，跨平台走法不存在，总走法从 $a_{15}$ 降到 $a_{12}\times a_{3}$ | M-T-387-E1 |
| 数值巧合不等于推理正确：误以为「甲去哪个项目等可能」直接答 $\frac23$，数值碰巧对但推理是错的 | M-T-388-V3 |

## 概率统计

### 几何概型（M-T-406 / 409 / 410）

**坐标系型通法**：设两人到达时刻为 $x,y$，样本空间是正方形，
条件 $\lvert x-y\rvert\le d$ 是夹在两条平行线间的带状区域：

$$P=1-\frac{(\text{边长}-d)^{2}}{\text{边长}^{2}}$$

> **算对立事件**（两个直角三角形）比直接算带状区域省事得多。（M-T-410-E1）

**只取决于比例** $\frac d{\text{边长}}$ —— 所以「$24$ 小时等 $4$ 小时」与「$300$ 米相距 $50$ 米」
答案同为 $\frac{11}{36}$（比例都是 $\frac16$），单位统一与否不影响结果。（M-T-410-V1、M-T-410-V2）

**体积型**（M-T-409）：

| 结论 | 来源 |
|---|---|
| $4$ 个小球体积和**恰好**是大球的一半 —— 命题人精心设计，于是「相交部分」和「外部」自然分居 $\frac12$ 两侧 | M-T-409-E1 |
| 正四面体内按比例分层，**用相似比立方**：$\frac{V_{\text{上}}}{V}=(\frac{H-h}{H})^{3}$ | M-T-409-V1 |
| 建系后三个坐标平面天然两两垂直（$3$ 对），法向量 $(1,1,1)$ 与三坐标轴点积都为 $1$，一眼看出不垂直 | M-T-409-V2 |

**易错点**：

| 结论 | 来源 |
|---|---|
| $x=\frac\pi2$ 处 $\tan x$ 无定义，必须把区间断开，否则会漏掉 $[\frac{3\pi}4,\pi]$ 这段 | M-T-406-V2 |
| $8{:}00$ 之后到的人**只能等 $8{:}30$ 那班**，$8{:}00$ 已开走 | M-T-406-V4 |
| 「某边是三角形最大边」⟺ 该边 $\ge$ 其余两边，建系后化为两个圆内区域取交集 | M-T-406-E1 |

### 古典概型（M-T-404）

| 结论 | 来源 |
|---|---|
| 某特定元素落在第 $k$ 位的概率，用对称性直接得 $\frac1n$，不必算排列数 | M-T-404-V3 |
| $(2,\frac52)$ 恰好等于 $5$，「大于 5」不含等号 —— 漏掉会数成 $6$ 种得 $\frac35$（陷阱选项 C） | M-T-404-E1 |

## 添加新结论的格式

```markdown
| 结论 | 来源 |
|---|---|
| **一句话结论**，必要时给公式 | M-T-XXX-Vn |
```

要点：

1. **写「怎么想」而不是「这题答案是什么」** —— 题目会重复，思路才是资产
2. **题号必须标** —— `--check` 靠它判重，漏标会误报未收录
3. 易错点和通法都要收 —— 易错点往往更有价值
4. 能用表格对比的（如「恒成立」vs「有解」、球相同 vs 球不同）优先用表格
