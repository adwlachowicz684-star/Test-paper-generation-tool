# 来源：网页文本 / 粘贴文本 / LaTeX

## 组卷网等题库站点的局限

**实测：学科网、组卷网、菁优网、教习网等对沙箱 IP 全部 403**，
拿不到原始文件。用户在浏览器里打开页面后**把内容粘贴过来**是可行的路径。

粘贴过来的文本有个特点：**公式会整块消失**。

```
组卷网页面上看到的第 1 题：
  1. 已知集合，则（　　）A．B．C．D．
```

集合内容和四个选项全是空的。

**原因**：公式在这些站点里是独立于文本存储的对象，
纯文本快照里会整块丢失，而不是变成乱码。

所以网页来源的录入流程是：

```
粘贴文本  →  识别题干骨架（中文部分完整）  →  人工补公式  →  入库
```

**与图片流程类似，但中文部分准确得多**（不用 OCR，直接复制）。

## 网页文本还带什么

题库站点会额外提供元数据，这些是 PDF 里没有的：

| 元数据 | 页面上的样子 | 对应字段 |
|---|---|---|
| 难度系数 | `容易 (0.85)` / `适中 (0.65)` / `困难 (0.4)` | `difficulty` |
| 题型细分 | `多选题-2个答案` / `填空题-单空题` / `解答题-证明题` | `subtype` |
| 解题方法 | `辅助角公式` / `向量法求线线角` | `review`（参考） |
| 来源 | `2025·江苏南通·模拟预测 · 名校` | `src` |
| 知识点 | `根式不等式 交集的概念及运算` | `kp` / `kp2` |

**这些字段质量比自动提取的高得多**，录入时优先采用。

难度系数直接对应：

| 页面标注 | 系数 |
|---|---|
| 容易 | 0.85 |
| 适中 | 0.65 |
| 较难 | 0.4 |
| 困难 | 0.15 |

题型细分直接填 `subtype`：
`单选题` / `多选题-N个答案` / `填空题-单空题` / `解答题-证明题` / `解答题-问答题`

## 网页的细目表

页面底部通常有细目表：

```
题号 | 难度系数 | 详细知识点 | 备注
1    | 0.85     | 根式不等式 交集的概念及运算
9    | 0.65     | 复数的除法运算 ... 2个答案
```

**这是高质量的结构化信息**——题号、难度、知识点、答案个数全有。
录入前先读它，比逐题猜快得多。

## 纯 LaTeX 来源

如果用户直接给 LaTeX 源码（比如从某些题库导出）：

多数命令系统已支持（见 `20-latex.md`）。
不常见的命令会**去掉反斜杠保留名字**输出，
页面上能看到，便于发现并手动替换。

处理流程：

1. 全文扫一遍非支持命令
2. 替换成支持的等价写法，或展开成纯文本
3. 包 `$...$` 定界符
4. 入库

## Markdown 来源

Markdown 里的 `$...$` / `$$...$$` 直接可用。
注意 `$$` 是行间公式，系统只支持行内，**统一改成单 `$`**。

表格形式的题目（Markdown 表格）需要先拆成字段。

## 录入检查

网页/文本来源相对 PDF 少了一类问题（没有矢量括号丢失），
但多了一类：**公式整块缺失**。

所以检查重点不同：

- [ ] 公式已补全（网页文本里公式是整块消失的，需按原文重建）
- [ ] 选项是否齐全（网页上选项常整块消失）
- [ ] 细目表的信息用上了没（难度、知识点、答案个数）

`review` 注明来源：「组卷网页面文本，公式经人工补全」。
