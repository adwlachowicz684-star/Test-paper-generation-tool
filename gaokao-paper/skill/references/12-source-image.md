# 来源：图片（拍照 / 截图 / 扫描件）

## 硬性前提：OCR 出不了公式

**下面每条都是实测结论，直接用，省得重复试。**

对真实试卷版面跑 `tesseract -l chi_sim+eng --psm 6`：

```
原卷：A. (-∞,-1) ∪ (0,+∞)
OCR：A. (—00,-1) U (0,+%)

原卷：f'(x)
OCR：广(z)
```

- 无穷 `∞` → `00`
- 并集 `∪` → `U`
- 导数符号 `'` → 丢失，且 `x` 被认成 `z`
- 分式、根号、上下标**全部无能**

已装语言包：`chi_sim` `chi_tra` `eng` `osd`。
**没有 `equ`（公式识别）包**，也没有 easyocr / paddleocr。

## 因此：图片只能走「骨架 + 重建」

```
OCR 拿中文文字骨架  →  人工读图补公式  →  LaTeX 重建  →  入库
```

**OCR 的输出只用来确认"有哪些字、什么顺序"，
公式部分必须看着原图人工重建。**

这是图片录入相对 PDF 的根本劣势：**PDF 至少坐标是准的，
图片连坐标都没有，全靠眼睛看**。

所以来源优先级：**文字版 PDF > 原生 Word > 图片**。
拿到材料先确认有没有文字版，再决定走哪条路。

## 操作步骤

### 1. 预处理

```python
from PIL import Image, ImageOps
im = Image.open(path)
im = ImageOps.grayscale(im)              # 灰度
im = im.resize((im.width*2, im.height*2), Image.LANCZOS)  # 放大 2x
im.save('/tmp/ocr_in.png')
```

放大能显著提升 OCR 准确率。歪斜的话先 `im.rotate(angle, expand=True)`。

### 2. OCR 拿骨架

```python
import subprocess
r = subprocess.run(['tesseract', '/tmp/ocr_in.png', 'stdout',
                    '-l', 'chi_sim+eng', '--psm', '6'],
                   capture_output=True, text=True)
print(r.stdout)
```

`--psm` 选择（**实测数据，不是猜测**）：

对真实教辅页面（dpi 200，放大 2x，灰度）跑四个模式，
与 PDF 文本层的真实中文做比对：

| psm | 输出字符 | 中文命中率 | 乱码率 |
|---|---|---|---|
| 4 | 3250 | 90.7% | 14.8% |
| **6** | **4350** | **89.8%** | **12.0%** ← 综合最好 |
| 11 | 2372 | 84.2% | 21.4% |
| 12 | 2330 | 84.2% | 21.1% |

**默认用 `--psm 6`**（假定是统一的文本块）。单列排版可试 `4`。

`11` / `12`（稀疏文本）**反而更差**——直觉上试卷留白多应该用稀疏模式，
但实测命中率降 5 个百分点、乱码率翻倍。稀疏模式会把公式区域
当成噪声丢掉，而那些区域里往往夹着中文。

凭实测数据决定，版面特征会误导。

### 3. 人工读图补公式

用 Read 工具**直接看原图**，把 OCR 输出里的乱码位置对应回原图，
人工判断那里原本是什么公式，按 `20-latex.md` 写成 LaTeX。

**OCR 结果只取中文骨架，公式看原图重建。**

看到 `—00` 能猜出是 `∞`，但写正则批量替换会引入新错误
（同一串字符在不同位置含义不同）。直接对着原图重建更快也更准。

### 4. 入库

同模式 A 流程，`review` 字段注明「来源为图片，公式经人工重建」。

## 多页 PDF 扫描件

先转成图片再逐页处理：

```python
import pymupdf
d = pymupdf.open(path)
for i, page in enumerate(d):
    page.get_pixmap(dpi=200).save(f'/tmp/page_{i:03d}.png')
```

dpi 200 够用，300 更准但慢。200 对中文识别已经足够。

## 质量预期

| 内容 | OCR 可靠性 | 处理方式 |
|---|---|---|
| 中文题干（无公式部分） | 较好，90%+ | OCR 直接用，人工校对 |
| 数字、字母 | 好 | OCR 直接用 |
| 选项标记 A/B/C/D | 好 | OCR 直接用 |
| **分数、根号** | **不可用** | 看原图人工重建 |
| **上下标** | **不可用** | 看原图人工重建 |
| **函数/区间括号** | **不可用** | 看原图人工重建 |
| **希腊字母** | 差（θ/α 常错） | 看原图确认 |
| **几何图形** | 无 | 需切图，见下 |

## 图片类题目

带图的题需要把图切出来存成切片。切片目录 `src/slices/<科目>/`，
命名 `<题目ID>_<序号>.png`，题目里 `figs` 字段存文件名。

切图后**必须人工确认图里没有混入相邻题目的内容**——
自动切图按 y 区间，遇到两题挨得近会切错。
