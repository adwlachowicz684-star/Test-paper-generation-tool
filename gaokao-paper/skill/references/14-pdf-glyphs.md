# 教辅 PDF：符号还原与图题处理

教辅（含《2024高中数学热点题型归纳完整解析版》）用 MathType / PMExtra 字体排公式，
数学符号落在 **Unicode 私用区**，常规 `get_text()` 直接吞掉。
这会让提取出的题干自相矛盾——例如 `f(x)-f(x)=2`（丢了撇号）、`f(x)=x+1` 恒假。

本篇给一套**可复刻的三步法**：还原符号 → 核实存疑 → 处理图题。
配套工具已就位，直接跑命令即可，不需要临时写脚本。

---

## 一、还原符号：`tools/dump_pdf.py`

### 用法

```bash
cd /data/workspace/gaokao-paper
PDF=/data/inputs/2024高中数学热点题型归纳完整解析版.pdf

# 1) 按特征词定位题目（最常用，先看这个）
python3 tools/dump_pdf.py "$PDF" --find '有300 个不同的实数根' --context 1200

# 2) 整页还原（题目跨页、或要看一页全貌时）
python3 tools/dump_pdf.py "$PDF" --pages 44 45

# 3) 字符级（判定某个符号到底是圆括号还是方括号时用）
python3 tools/dump_pdf.py "$PDF" --pages 44 --chars --y0 95 --y1 152 --x0 320 --x1 580

# 4) 统计全书私用区码位（换了一本新教辅时先跑这个）
python3 tools/dump_pdf.py "$PDF" --glyphs
```

`--find` 会打印命中处**前后**共约 `--context` 字符，含【答案】【详解】——
详解是校验题干自洽性的唯一依据，一定要一起读。

### 已验证的码位映射

| 码位 | 还原为 | 出现次数 | 说明 |
|---|---|---|---|
| `U+F0EE` | `(` `)` | 29059 | 圆括号，左右同码，按 x 坐标交替判左右 |
| `U+F0F6` | `[` `]` | 2289 | 方括号，同上 |
| `U+F0F4` | `\|` | 4286 | 绝对值竖线 |
| `U+F00A` | `′` | 2291 | 导数撇号 `f′(x)` |
| `U+F001` | `·` | 20278 | 目录点线、填充点 |
| `U+F026` | `‾` | — | 平均值上划线 `ȳ` |

**开闭区间就靠 `U+F0EE` 与 `U+F0F6` 区分。** 这是高频考点：
两个选项内容看着"重复"，实际一个是开区间、一个是闭区间，答案完全不同。

例（页 44 变式 12）：
```
A. (-e - 1/e,-5/2)     ← U+F0EE，开区间
B. [-e - 1/e,-5/2]     ← U+F0F6，闭区间
```

### 还原前后对照

| 场景 | 未还原 | 还原后 |
|---|---|---|
| 导数 | `f(x) - f(x) = 2`（恒假、无解） | `f(x) - f′(x) = 2` |
| 绝对值 | `f(x)=ln(x-1)` | `f(x)=\|ln(x-1)\|` |
| 区间 | 选项 A/B 内容相同 | A 开区间 / B 闭区间 |

### 换行与分数

还原后的文本仍是**按视觉行**排列，分数被拆成上下两行：

```
A. (-e - 1/e,-5/2)   B. [-e-1/e,-5/2]
   e  2                  e  2          ← 分母行单独一行
```

按 `20-latex.md` 还原成 `\frac{1}{e}`、`\frac{5}{2}` 即可。

### 换一本新教辅时

码位映射是**字体相关**的，换书要重跑一次 `--glyphs` 核对：

```bash
python3 tools/dump_pdf.py 新书.pdf --glyphs
```

对表里没有的码位，用 `--chars` 看它**夹住了什么**：
成对出现在表达式两侧的即括号类，紧贴字母右侧且在函数后的即撇号。

## 二、核实存疑题

遇到"看不懂""答案对不上""选项重复"的题，按下表逐条核实，
**核实完再决定录不录**。实测本批次 3 道"存疑"题全部核实通过、一道没丢。

| 存疑类型 | 核实动作 |
|---|---|
| 选项看着重复 | `--chars` 看括号码位，判断是开闭区间之别 |
| 答案与自算不符 | 重算一遍；**优先怀疑自己的分支漏了** |
| 方程恒真/恒假 | 十有八九丢了撇号或竖线，看 `--chars` |
| 纯图解题 | 走第三节切图流程，图能切就能录 |

**自算与标答不符时，先怀疑自己。** 实测案例：算某题上限应为 `9/4`，
怀疑原书印错；重算后发现是漏了 `u₂=5/4` 这一支，
补上后正好撑起标答中 `(-5/2,-9/4)` 那一段——原书无误。

核实结论写进 `review` 字段，把推理链留下来：

```python
'review': (
    r"★ 曾误判此答案偏大（以为上界应为 $\frac{9}{4}$），"
    r"独立验算后发现是漏了情形二：$u_{2}=\frac{5}{4}$ 时 "
    r"$f(x)=\frac{5}{4}$ 有 $2$ 个解，补上后与标答 A 完全吻合，原书无误。"
),
```

## 三、图题切图：`tools/cut_figs.py`

图题以前只能跳过。现在切图→入库→三端渲染整条链路已跑通（网页 / HTML / Word 均验证过）。

### 三步走

```bash
PDF=/data/inputs/2024高中数学热点题型归纳完整解析版.pdf

# 1) 列出该页所有图及位置（页码是 0-based）
python3 tools/cut_figs.py "$PDF" --list 45

# 2) 校验候选框（确认没切进邻题）
python3 tools/cut_figs.py "$PDF" --check 45 --boxes 332,491,442,601 457,493,557,601

# 3) 切图，文件名用题目 ID
python3 tools/cut_figs.py "$PDF" --cut 45 --qid M-H0190 \
    --boxes 332,491,442,601 457,493,557,601
```

`--list` 输出示例（页 45 右栏两张并排图）：

```
  #3  xref=262  原始 208x217  位置 (334,492)-(440,602)  → --boxes 334,493,440,603
  #4  xref=265  原始 208x234  位置 (458,494)-(555,602)  → --boxes 459,495,555,603
```

直接把 `--boxes` 后面的数字抄给 `--check` / `--cut` 即可。

### 校验判据

脚本看的是**框内**有没有邻题文字：

- 框内无文字 → 纯曲线图，安全
- 框内只有 `O` `x` `y` 或数字 → 坐标轴标注，正常
- 框内有中文正文 → 切歪了，收窄该框

框外紧贴着 `A. 1 / B. 2` 这类选项属正常（题目排版本就如此），只作提示不报错。

### 命名与存放

切出的图落在 `src/slices/数学/{题目ID}_fig{n}.png`，如 `M-H0190_fig1.png`。
三端都按 `{ID}_fig{n}` 在 `src/slices/<科目>/` 下找，**文件名不能自定**。

### 填入题目

`--cut` 会直接打印可粘贴的 figs 列表：

```python
'figs': [{'file': 'M-H0190_fig1.png', 'w': 459, 'h': 460, 'kb': 10},
         {'file': 'M-H0190_fig2.png', 'w': 417, 'h': 451, 'kb': 29}],
```

### ID 还没确定时

入库后才知道 ID。做法是**先按预估 ID 切图**，入库后若不符再改名：

```python
# 预估：当前最大 M-H 号 + 本批内序号
mx = max(int(q['id'][3:]) for q in bank if re.match(r'^M-H\d+$', q['id'] or ''))
pred = 'M-H%04d' % (mx + idx + 1)
```

```bash
# 实际 ID 与预估不符时改名
python3 tools/cut_figs.py "$PDF" --rename M-H0190 M-H0191
```

改名后记得同步改 `bank.json` 里该题 `figs` 的 `file` 字段。

### 图题的 review 怎么写

记清楚图的来源和校验结论，方便后人复核：

```python
'review': (
    r"★ 纯图解题，图由 PDF 页45 右栏切取（两张并排，左 f(x)、右 g(x)）。"
    r"切图边界已用 cut_figs.py --check 校验：框内无文字，纯曲线与坐标轴。"
    r"若发现图序或图内容与题面不符，以原书为准复核。"
),
```

## 四、完整流程（一批图题+文字题混排）

```
1. dump          tools/dump_pdf.py --find '特征词'      ← 还原符号后的原文
2. 读详解        用【详解】反推题干自洽（见 21-review-rules.md）
3. 存疑核实      按第二节逐条核实，不轻易跳过
4. 图题切图      tools/cut_figs.py --list / --check / --cut
5. 写入脚本      tools/input_batchNN.py（含 figs 字段）
6. 入库          tools/commit_batchNN.py
7. 导出核对      export-html / export-docx + tools/check_render.py
8. 回归          selftest.py + test.mjs + check_skill_docs.py
```

第 4 步只对图题做，其余题跳过。
