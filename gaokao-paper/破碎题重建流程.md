# 破碎题重建流程

> 面向「PDF 提取损坏 / 选项 OCR 塌缩 / 详解截断」类题目的**标准化处置流程**。
> 配套工具：`tools/scan_recoverable.py`。
> 首次实战：第 134 批（救回 5 题）。

---

## 一、背景：一个代价不小的误判

项目后期把 27 道题统一登记为 `reason = 提取破碎`，据此长期搁置。
第 134 批回查原件后发现：**这个判断的依据不可靠**。

当时的依据是 `data/ref_bank.json` 的提取结果——但它只是中间产物。
真正的原始文本在 `原件/按页还原/pXXX.txt`（457 页）里，**信息量大得多**：

| 题 | 此前判定 | 回原件后 |
|---|---|---|
| M-T-374-V3 | 四个选项 OCR 全塌 | 选项 `5/3 5/4 4/3 3/2` **完好** |
| M-T-109-V1 | solution 自我循环 | 该题编号其实是 M-T-110-V1；**本条详解完整** |
| M-T-303-V3 | 选项括号全丢 | 详解完整，答案可由独立推导定形 |

**教训**：`ref_bank` 提取失败 ≠ 原题不可录。判「破碎」前必须先回原件核对。

---

## 二、核心原则

### 原则 1：先回原件，再下结论

```
ref_bank 字段残缺
      ↓ 不要直接判死
读 原件/按页还原/p{page}.txt
      ↓
仍残缺？ → 才进入可救性评级
```

`python3 tools/scan_recoverable.py --key M-T-XXX-V1` 会自动做这一步。

### 原则 2：可降级录入（最重要的一条）

一道选择题若满足 **题干完整 + 详解完整 + 答案可独立验证**，
仅四个选项 OCR 损毁，**不要放弃**——

> **改成填空题/解答题录入：去掉选项、保留问答与详解。**

题目价值就此保住，且**顺带消解「原书选项与答案矛盾」的死结**。

实例（第 134 批）：
- **M-T-375-V1**：选项碎成两行数字 `5 5 4 3 / 3 4 3 2` 且都 $>1$，不可能是椭圆离心率 → 改填空，答案 $e=\frac37$
- **M-T-243-V1**：四个选项全塌成 `ΔABC`；原书 `ans` 字段标 C、详解末句却写「故选 D」 → 改填空，答案 $5$，矛盾自然消解

### 原则 3：独立推导是唯一硬判据

「算出来矛盾」是识别 OCR 错误的最强信号。反之，**能用题干独立算出与原书标答一致的答案，就是还原正确的充分证据**。

## 三、四级可救性判据

| 级 | 含义 | 判据 | 处置 |
|---|---|---|---|
| **A** | 直接可录 | 题干 ≥45 字 + 选项完好 + 详解 ≥260 字 | 正常入库 |
| **B** | 需推导补全 | 题干与选项在，详解缺失/过短 | 自己算一遍，补写详解 |
| **C** | 可降级录入 | 题干 + 详解完整，**仅选项不可用** | 改填空/解答题 |
| **D** | 不可救 | 核心信息在未提取的图中；或题干与详解同时破碎 | 登记跳过，留痕 |

### 退化识别

选项「看似存在」实则塌缩时，不能算完整：

- **同形碎片**：四项去重后只剩 1 种（如全是 `ΔABC`）→ 视为无选项
- **纯数字碎片**：只余 `10\n10 ,1` 之类 → 需按原则 3 重建

### 图形依赖

题干含 `如图 / 图象 / 三视图 / 网格纸 / 俯视图 / 展开图` 等词时：

- 详解仍完整 → 判 **C**（可降级，图形多半只影响选项）
- 详解也缺 → 判 **D**

## 四、标准作业流程（SOP）

```
①  python3 tools/scan_recoverable.py --reason 提取破碎 --min A
        ↓ 拿到 A/B/C/D 分级清单
②  按 A → B → C 顺序取题（同页聚堆优先）
        ↓
③  读原件页文本，确认题干、选项、详解的真实状态
        ↓
④  独立推导一遍 —— 这是硬判据，不能省
        ↓
⑤  与 ref_bank 的 ans 字段对拍
        ├─ 一致 → 按可救性级别录入
        └─ 不一致 → 再算一次；确认后记 A 类勘误
        ↓
⑥  录入（C 级改为填空/解答）
        ↓
⑦  数值验证：代入临界值、扫描取等点
        ↓
⑧  更新 skipped.json：reason 改为「已补录」，note 写清还原依据
        ↓
⑨  python3 tools/run_batch.py <批号>
```

## 五、工具用法

```bash
# 全量扫描（排除已补录）
python3 tools/scan_recoverable.py

# 只看某个原因
python3 tools/scan_recoverable.py --reason 提取破碎

# 只看 A / B 级（可直接下手的）
python3 tools/scan_recoverable.py --min B

# 单题核对
python3 tools/scan_recoverable.py --key M-T-303-V3
```

## 九、第 135 批新增：两条判据

### 判据一：「如图」题的图形数据回填（C 级主力救法）

p179–p180 的 M-T-214 四题题干都写「部分图象如图所示」，此前一律判为依赖图形、不可录。
回原件核对后发现：**原书详解把图中读出的每一个数据都写全了**——
最高点坐标、最低点坐标、周期算式，一个不缺。

于是可以**反向使用详解**：把图中数据回填进题干，题目就脱离原图也能独立作答。

| 题 | 详解给出的图形数据 | 回填后的题干补充 |
|---|---|---|
| M-T-214-V1 | $T=\dfrac43\left[\dfrac{5\pi}{12}-\left(-\dfrac\pi3\right)\right]$，最高点 $\left(\dfrac{5\pi}{12},2\right)$ | 补「最高点 …, 周期 $T=\pi$」 |
| M-T-214-E1 | $\dfrac T2=\dfrac{7\pi}{12}-\dfrac\pi{12}$，最高点 $\left(\dfrac\pi{12},2\right)$ | 补「最高点 …, 最低点 $\left(\dfrac{7\pi}{12},-2\right)$」 |
| M-T-214-V2 | $A+B=1,\-A+B=-3$，最高点 $\left(\dfrac\pi{12},1\right)$ | 补「最大值 $1$、最小值 $-3$」 |
| M-T-214-V3 | $\dfrac{13\pi}{12}-\dfrac\pi3=\dfrac34T$，最高点 $\left(\dfrac{13\pi}{12},2\right)$ | 补「最高点 …, 零点 $\left(\dfrac\pi3,0\right)$」 |

**回填后必须做数值复核**：把求出的解析式代回图中各点，把值域端点与扫描结果比对。
本批四题全部逐位吻合（如 V2 的 $f(\frac\pi{12})=1$、$f(\frac{7\pi}{12})=-3$）。

> ⭐ 推广：凡是 C 级里「题干含如图但详解完整」的题（M-T-174-V3、M-T-293-V2、M-T-315-V1、
> M-T-319-V1、M-T-325-E1/V1、M-T-326-V1、M-T-378-V3 共约 8 题），都可套这个流程。

### 判据二：单选唯一性校验（识别「齐备但不自洽」）

第 135 批发现一个新问题：**A 级（题干/选项/详解齐备）不等于内部自洽**。

M-T-116-E1 的详解推出 $2f(\frac\pi6)<f(\frac\pi2)$，这与 A 选项 $f(\frac\pi2)>2f(\frac\pi6)$
是同一个不等式——A 与标答 C 同时成立，单选题却只给 C。

**校验方法**：取 2 个满足题设的具体函数代入，看是否只有标答唯一为真。

```
M-T-116-V1（答案 B）
  f(x)=x      → A假  B真  C假  D假   ✓ 与单选答案一致
  f(x)=x^3    → A假  B真  C假  D假   ✓
M-T-116-E1（答案 C）
  f(x)=sin^2x      → A真  C真        ✗ 两个都对，单选不成立
  f(x)=sin x·e^x   → A真  C真        ✗
```

这个方法还顺带解决了**根号还原**：M-T-116-V1 的 A 选项提取为 $2f(\frac\pi6)>f(\frac\pi4)$，
但若不含 $\sqrt2$，$f(x)=x$ 会使 A 也为真，与单选矛盾；补回 $\sqrt2$ 后四选项恰好一真三假。

**判据**：$\dfrac1{\sin\theta}$ 出现在系数位置时，$\dfrac1{\sin\frac\pi4}=\sqrt2$、
$\dfrac1{\sin\frac\pi3}=\dfrac2{\sqrt3}$ 都会带来根号，OCR 丢失后必然破坏单选唯一性。

> ⭐⭐ 建议：**每道 A 级选择题入库前，用 2 个具体函数做一次单选唯一性校验**。
> 成本极低（一段 lambda），但能同时抓出「根号丢失」和「原书标答存疑」两类问题。

## 十一、第 136 批实战：回填法在立体几何上的验证（本批录入 8 题）

### 「图形数据回填」从三角函数推广到立体几何

第 135 批只在「给图求解析式」一类上用过回填法。本批在**立体几何与三视图**上验证，
结论是：**该方法与题型无关，只取决于「详解有没有把图中读出的量写出来」**。

| 题 | 题型 | 详解给出的图中数据 | 回填方式 |
|---|---|---|---|
| M-T-174-V3 | 三角·给图求解析式 | $f(0)=\sqrt3$、零点 $\frac\pi3$、$\frac{7\pi}{12}-\frac\pi3=\frac14T$ | 三个量写进题干括号 |
| M-T-293-V2 | 三视图 + 直观图 | 直三棱柱、底面等腰直角、两侧面为边长 $a$ 的正方形 | **整段改写为文字几何体**，不再提「如图」 |
| M-T-325-E1 | 立体几何折叠 | 边长 $3$、分点比 $\frac12$、面面垂直 | 条件本就在文字里，「如图」可直接保留 |
| M-T-325-V1 | 立体几何构型 | 矩形 + 等腰 $\triangle BCF$ + $EA\parallel FC$ | 同上 |

> ⭐ **关键认识**：三视图类题目（此前一律判 D 级）其实**最容易回填**——
> 因为详解必须先还原几何体的形状与尺寸才能算体积/外接球，
> 这些描述天然就是一段完整的文字。M-T-293-V2 因此从 D 级直接提到可录。

> ⭐ **新的可救性信号（补进 §四判据）**：
> 若详解**第一步**就出现具体边长、坐标或分点比例，这些数据几乎一定来自图，
> 可回填；若详解只写「由图可知」而$\ $不给数值，才确属 D 级。

### 「算出来矛盾」反推的三条硬判据

1. **用「两侧最小值相等」锁死还原**（M-T-130-V3）
   右侧 $\frac1{a^2\mathrm e^2}+\frac1{64b^2}+\frac{ab}8$ 的最小值算出来是 $\frac1{2\sqrt{2\mathrm e}}$，
   而它恰好等于题给的 $f\left(\frac12\right)$。这个「巧合」一次性锁定了三处被 OCR 吃掉的部分。
   > ⭐ 通法：**题目里两个看似无关的量若数值相等，通常是命题人刻意设计的，可作为还原的唯一锚点。**

2. **用恒等式反推图形的边**（M-T-315-V1）
   详解用 $AC^2+CD^2=AD^2$ 证垂直，代入得 $AC=CD=2\sqrt2$、$AD=4$，反推出 $AB=BC=2$。
   > ⭐ 通法：**详解中的勾股/相似恒等式，反过来就是边长的方程组。**

3. **用「后续可解性」反推定义**（M-T-325-V1）
   题干只说「$\triangle BCF$ 为等腰三角形」，未指明腰。但由 $EA\parallel FC$ 且 $AE\perp$ 底面
   可得 $\angle BCF=90^\circ$，等腰三角形有直角则该角必为顶角，故 $BC=CF=b$ 唯一确定。
   > ⭐ 通法：**若某定义不明确会导致后续无解，则唯一能使题目可解的那个解释就是原意。**

## 十二、第 138 批新增：回原件反推的三条判据（本批录入 7 题）

第 138 批的 7 题里，有 6 题此前被判为「答案存疑 / 提取破碎 / 无效条目」，
回原件逐页核对后全部救回。新增判据如下。

### 判据 A：分式排版被 OCR 拆开 ⟹ 用详解的导数分子反推

**症状**：题干看起来是乘积不等式，但与详解的导数符号矛盾。

**实例（M-T-116-E1，p082）**：提取文本作
`f(x) sinx < f(x) cosx`，据此得 $\left(\frac f{\sin x}\right)'<0$，
而详解却写 $g'(x)=\frac{f'(x)\sin x-f(x)\cos x}{\sin^{2}x}>0$ —— 方向相反。

回原件看竖排分式才明白，原题是
$$\frac{f(x)}{\sin x}<\frac{f'(x)}{\cos x}$$
提取时分子被拆到上一行、**导数撇号丢失**，于是两个分式被读成了两个乘积。

> ⭐ **判据**：**详解的导数分子就是题干的还原蓝本。**
> 看到 $u'v-uv'$ 形状的分子，题干必是分式不等式 $\frac uv<\frac{u'}v$ 之类，
> 而非乘积不等式。反过来写回题干，再验证方向是否让 $g'$ 的符号与详解一致。

### 判据 B：定义域开区间是选项真伪的开关

**同一道题**的第二处教训：我第 135 批把它登记为「A、C 同时成立，原书标答存疑」，
本批回原件后确认**原书答案 C 正确**。

原因：题干定义在**开区间** $\left(0,\frac\pi2\right)$，而 A 选项含 $f\left(\frac\pi2\right)$ ——
$\frac\pi2$ 不在定义域内，$f\left(\frac\pi2\right)$ 无定义，A 不成立。

> ⭐ **判据**：**含参判断型选择题，先扫一遍各选项的自变量是否落在定义域内。**
> 开区间端点处的函数值是最经典的排除项。这一步零成本，但漏了就会误判原书出错。
>
> ⚠ 反过来也提醒：判断「原书标答是否存疑」之前，务必先排除自己漏看定义域的可能。

### 判据 C：三视图 ⟹ 详解已把几何体写成文字

此前三视图题一律判 D 级。但 M-T-294-V3 的详解写：
「它是从一个四棱锥截下的部分……四棱锥又可以看作是从**边长为 $3$ 的正方体**中截取出来的，
所以三棱锥的外接球就是截取它的正方体的外接球」。

**几何体已被完整描述**，直接回填成「棱长为 $3$ 的正方体截得的三棱锥」，
原选项 $3\pi/12\pi/18\pi/27\pi$ 与答案 D 全部保留，题目完全独立。

> ⭐ **判据**：三视图题不看作图题，先看详解**第一步有没有给出具体尺寸**。
> 给了就能文字化；只写「由三视图可知」而无数值，才确属 D 级。

### 判据 D（补充）：图形选择题降级的三种落点

第 135、136 批已验证回填法可用于三角函数与立体几何。本批再细化落点选择：

| 详解给出的东西 | 降级为 | 实例 |
|---|---|---|

留下会误导学生的废话。

### 判据 E：B 级「详解为空」⟹ 独立推导 + 数值验证

M-T-210-V2（向量与四心）此前被误标为「无效条目」，实际是题号漂移。
题干与选项完整、详解为空，我独立推导：
$$\overrightarrow{AP}\cdot\overrightarrow{BC}
=\lambda\left(\frac{-ac\cos B}{c\cos B}+\frac{ab\cos C}{b\cos C}\right)=\lambda(-a+a)=0$$
关键在于 $\overrightarrow{AB}$ 与 $\overrightarrow{BC}$ 的夹角是 $\pi-B$（不是 $B$）。

> ⭐ **强制动作**：独立推导的题必须做数值复核。本题随机取 4 组不共线三点，
> $\overrightarrow{AP}\cdot\overrightarrow{BC}$ 分别为 $3.5\times10^{-16}$、
> $-7.6\times10^{-16}$、$-1.9\times10^{-14}$、$-2.4\times10^{-15}$，确认恒为 $0$。
