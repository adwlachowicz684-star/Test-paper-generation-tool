# 原件目录

教辅 PDF、按页提取的原文、**全书还原版**、题型页码索引。**给多个窗口并行录题用的**。

```
原件/
├── README.md                              本文件
├── 题型页码索引.md                          ← 并行分工表，先读这个
├── 2024高中数学热点题型归纳完整解析版.pdf     21 MB，456 页，原件
├── 按页还原/          ★ 录题首选          456 个 txt，共 2.3 MB
│   ├── p001.txt                            带 LaTeX 结构（\frac ^ _）
│   ├── _index.json                         页 → 检出结构数
│   └── ...
└── 按页原文/          （对照用）            456 个 txt，共 2.2 MB
    ├── p001.txt                            未还原的平文本
    └── ...
```

## ★ 两个「按页」目录的区别（重要）

| 目录 | 内容 | 什么时候读 |
|---|---|---|
| **按页还原/** | `\frac{x - a + 1}{e^{x}}`、`x^{2}` | **默认读这个**，题干不会破碎 |
| 按页原文/ | `x - a + 1` / `2ex`、`x2` | 还原版看不懂时对照；或核对是否有误检 |

举例，同一处 `f'(x)`：

```
按页原文：  f′(x) = a -= + a / ex ex / 1 - (1 + x) x     ← 没法读
按页还原：  f'(x) =\frac{1 + x}{e^{x}} + a               ← 直接用
```

还原版由 `tools/restore_all.py` 一次生成（全书 85 秒），
检出 **6242 处分数、4110 处上下标**，覆盖全部 456 页。

## 并行录入怎么用

**第 1 步：认领题型段**

打开 `题型页码索引.md`，找一个「待录 > 0」且别人没在做的题型段。
表里每行有：题型编号、PDF 页码、对应原文文件、总题数、**待录题数**、
以及每题的完成状态（`V1✓` 已录 / `E1重` 重复 / `V2跳` 跳过）。

**第 2 步：读还原版的那几页（不是原文！）**

```bash
cat 原件/按页还原/p033.txt
```

注意索引里的 `p033.txt` 在**两个目录下同名**，
录题时请一律取 `按页还原/` 下的那份。

**第 3 步：需要精确核实时再取 PDF**

只有这几种情况才需要原件：

| 场景 | 命令 |
|---|---|
| 符号存疑，看字符码位 | `dump_pdf.py <pdf> --pages 32 --chars` |
| 切图题 | `cut_figs.py <pdf> --list 45` |

2.3 MB 的 txt 比 21 MB 的 PDF 下载快一个数量级。
**多数窗口只需要还原版 txt，不必下载完整 PDF。**

## 还原版的已知误差

还原版是**机器出初稿、人工做判断**，以下几类需要人工处理：

| 现象 | 处理 |
|---|---|
| `⟨?⟩` | 未识别的私用区字符，用 `--chars` 查码位 |
| 根号 `√` 覆盖范围不明 | 人工按上下文补（唯一必须人工的部分） |
| 嵌套分数只出内层 | 人工套一层 |
| 偶有短线被误判成分数线 | 忽略即可 |
| 加减号可能缺失 | 结合原文与答案判断 |

**人工审核不能省。** 工具解决「猜结构」，人负责「判正误」——
题库是给孩子练的，答案错了比题目录得慢严重得多。
