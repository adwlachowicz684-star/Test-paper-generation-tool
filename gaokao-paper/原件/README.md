# 原件目录

教辅 PDF、按页提取的原文、题型页码索引。**给多个窗口并行录题用的**。

```
原件/
├── README.md                              本文件
├── 题型页码索引.md                          ← 并行分工表，先读这个
├── 2024高中数学热点题型归纳完整解析版.pdf     21 MB，456 页，原件
└── 按页原文/                               456 个 txt，共 2.2 MB
    ├── p001.txt
    ├── p002.txt
    └── ...
```

## 并行录入怎么用

**第 1 步：认领题型段**

打开 `题型页码索引.md`，找一个「待录 > 0」且别人没在做的题型段。
表里每行有：题型编号、PDF 页码、对应原文文件、总题数、**待录题数**、
以及每题的完成状态（`V1✓` 已录 / `E1重` 重复 / `V2跳` 跳过）。

**第 2 步：只读那几页原文**

```bash
cat 原件/按页原文/p033.txt
```

2.2 MB 的 txt 比 21 MB 的 PDF 下载快一个数量级。
**多数窗口只需要原文，不必下载完整 PDF。**

**第 3 步：需要精确核实时再取 PDF**

只有这几种情况才需要原件：

| 场景 | 命令 |
|---|---|
| 符号存疑，看字符码位 | `dump_pdf.py <pdf> --pages 32 --chars` |
| 切图题 | `cut_figs.py <pdf> --list 45` |
| 分数、根号（矢量绘制，文本层没有） | 只能看 PDF 图象 |

## 页码基准（容易差一页）

| 地方 | 基准 |
|---|---|
| `题型页码索引.md`、`pXXX.txt` 文件名 | **1-based** |
| `dump_pdf.py --pages`、`pdf2latex.py --page` | **0-based** |

所以索引写「第 33 页」，用 dump_pdf 要写成 `--pages 32`。

## 索引里的「?」是什么意思

`33–?` 表示只确定起始页是 33，结束页无法确定——TOC 里下一个题型的页码
不递增（该题型跨到别处，或 TOC 本身有跳跃）。

**实测命中率约 57%**（240/422 个题型），待录段里 76% 有明确页码。
标 `?` 的用特征词搜索定位：

```bash
python3 tools/dump_pdf.py <pdf> --find '题干里的特征短句' --context 1200
```

## 原件目录是生成物吗

- `按页原文/`：**生成物**，从 PDF 提取，PDF 不变就不用重新生成
- `题型页码索引.md`：**生成物**，`tools/make_index.py`，录完一批重跑即刷新
- PDF：**原件**，只读，不要改

重跑索引：`python3 tools/make_index.py`
